FREQUENCY ANALYSISDISTRIBUTION What it does: Counts how many mutant varieties exist for each category value, ranks them, and visualises the distribution. The essential first step of any MVD analysis.
  • Column selector: Crop, Country, Region, Mutagen type, Crop Group, Decade, Explant type, or Institution
  • Country + Region filters: restrict counts to a geographic subset before tallying — e.g. "top crops in Asia only"
  • Chart types: Horizontal Bar (best for ranked lists), Vertical Bar, Donut/Pie (proportions), Treemap (hierarchical)
  • Frequency table: count, %, cumulative % — copy-paste ready for publication methods sections
  • Typical finding: Pareto pattern — top 3–5 categories account for 60–80% of all varieties

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")
# Optional filters
# df = df[df["Country"].str.contains("Japan", case=False, na=False)]
# df = df[df["Region"] == "Asia"]

col, top_n = "Crop", 20

freq = df[col].value_counts().head(top_n).reset_index()
freq.columns = [col, "Count"]
freq["Pct"]  = (freq["Count"] / len(df) * 100).round(2)
freq["Cum%"] = freq["Pct"].cumsum().round(2)
print(freq.to_string(index=False))

fig, ax = plt.subplots(figsize=(10, top_n * 0.38 + 2))
ax.barh(freq[col][::-1], freq["Count"][::-1], color="#005A8E")
ax.set_xlabel("Varieties")
ax.set_title(f"{col} — Top {top_n}", fontweight="bold")
ax.spines[["top", "right"]].set_visible(False)
plt.tight_layout()
plt.savefig("mvd_freq.png", dpi=150, bbox_inches="tight")
plt.show()

TIME SERIESTREND TEST What it does: Shows how the number of released mutant varieties has changed over time and tests whether the trend is statistically significant. Key for understanding programme growth and technology adoption.
  • Annual / Decadal: bar charts per year or decade — peaks often correspond to major breeding investments or data submission batches
  • Annual + Cumulative: dual-axis showing rate and total growth side by side
  • Multi-Series: overlay categories on one time axis (e.g. Physical vs Chemical mutagen use over decades)
  • Mann-Kendall test: non-parametric, no normality assumption — suited for count data. Returns Kendall's τ, p-value, and Sen's slope (varieties/year)
Note: Release year lags mutagenesis by 5–15 years — this reflects release dynamics, not when mutations were induced.

import pandas as pd
import matplotlib.pyplot as plt
import pymannkendall as mk  # pip install pymannkendall

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")
df["Year_of_Release"] = pd.to_numeric(df["Year_of_Release"], errors="coerce")
# df = df[df["Crop"].str.contains("rice", case=False, na=False)]

annual  = df.groupby("Year_of_Release").size().reset_index(name="Count")
annual["Cumulative"] = annual["Count"].cumsum()
df["Decade"] = (df["Year_of_Release"] // 10 * 10).astype("Int64")
decadal = df.groupby("Decade").size().reset_index(name="Count")

fig, axes = plt.subplots(1, 3, figsize=(16, 5))
axes[0].bar(annual["Year_of_Release"], annual["Count"], color="#005A8E", width=0.9)
axes[0].set_title("Annual Releases", fontweight="bold")
axes[1].bar(decadal["Decade"], decadal["Count"], color="#00A19A", width=8)
axes[1].set_title("Decadal Distribution", fontweight="bold")
axes[2].plot(annual["Year_of_Release"], annual["Cumulative"], color="#E07B00", lw=2)
axes[2].set_title("Cumulative Growth", fontweight="bold")
for ax in axes: ax.spines[["top", "right"]].set_visible(False)
plt.tight_layout(); plt.savefig("mvd_temporal.png", dpi=150); plt.show()

result = mk.original_test(annual["Count"].values)
print(f"Trend   : {result.trend}")
print(f"p-value : {result.p:.6f}")
print(f"tau     : {result.Tau:.4f}")
print(f"slope   : {result.slope:.3f} varieties/year")
pandas — groupby(year/decade), cumsum() for running totals, to_numeric() for type conversion
matplotlib.pyplot — bar, line and dual-axis (twinx) charts; multi-panel subplots
pymannkendall — Non-parametric monotonic trend test. Returns trend direction, Kendall's τ, p-value, Sen's slope. No normality assumption — ideal for count data
CROSS-TABULATIONHEATMAP What it does: Cross-tabulates two categorical variables and visualises the joint distribution. Reveals dominant, rare, and absent combinations — the most information-dense view of the MVD.
  • Heatmap: colour-coded count matrix — immediately shows e.g. Japan dominates Rice × Gamma rays, or EMS is nearly exclusive to Europe
  • Stacked Bar (%): normalised to 100% — compare composition regardless of absolute programme size
  • Grouped Bar: side-by-side absolute counts — use when raw programme size matters
  • Bubble Grid: every row × column combination as a sized, colour-coded bubble — the most readable way to spot dominant and rare pairings at a glance
  • Table: raw cross-tabulation with row totals for export

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")
# df = df[df["Region"] == "Asia"]

row_col, col_col = "Country", "Crop_Group"
tr, tc = 12, 8
top_r = df[row_col].value_counts().head(tr).index
top_c = df[col_col].value_counts().head(tc).index
sub = df[df[row_col].isin(top_r) & df[col_col].isin(top_c)]
ct = pd.crosstab(sub[row_col], sub[col_col])

fig, ax = plt.subplots(figsize=(max(10, tc), max(6, tr * 0.45)))
sns.heatmap(ct, ax=ax, annot=True, fmt="d", cmap="Blues",
            linewidths=0.3, annot_kws={"size": 9})
ax.set_title(f"{row_col} x {col_col}", fontweight="bold")
plt.tight_layout(); plt.savefig("mvd_heatmap.png", dpi=150); plt.show()

# Stacked % composition
ct_pct = ct.div(ct.sum(axis=1), axis=0) * 100
ct_pct.plot(kind="bar", stacked=True, figsize=(12, 6), colormap="tab10")
plt.xticks(rotation=45, ha="right"); plt.ylabel("Percentage (%)")
plt.tight_layout(); plt.savefig("mvd_stacked.png", dpi=150)

MUTAGENTECHNOLOGY SHIFT What it does: Analyses which mutagenic agents have been used and how mutagenesis technology has evolved. Documents the shift from radiation-dominated early breeding toward chemical and ion-beam methods.
  • Distribution: Physical (gamma, X-ray, neutron, ion beam) vs Chemical (EMS, sodium azide…) proportions
  • Decadal Shift: gamma rays were near-exclusive before 1980; EMS and ion beams gained ground from 1990s onward
  • Crop × Mutagen Heatmap: distinct profiles per crop — rice favours gamma, barley leans to sodium azide, woody species use ion beams
  • Country × Mutagen: Japan's RIKEN ion-beam programme stands out; European programmes show strong EMS adoption
  • Dose Distribution: histogram of recorded doses (Gy for radiation, mM for chemicals) — data quality check

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")

def cat_mut(x):
    if pd.isna(x): return "Unknown"
    x = str(x).lower()
    if any(k in x for k in ["gamma","x-ray","neutron","ion beam","carbon"]): return "Physical"
    if any(k in x for k in ["ems","sodium azide","colchicine"]):              return "Chemical"
    return "Other"
df["Mutagen_Category"] = df["Mutagen_Type"].apply(cat_mut)

# Donut chart
cats = df["Mutagen_Category"].value_counts()
fig, ax = plt.subplots(figsize=(7, 6))
ax.pie(cats, labels=cats.index, autopct="%1.1f%%",
       wedgeprops=dict(width=0.55), startangle=90)
ax.set_title("Mutagen Distribution"); plt.savefig("mvd_donut.png", dpi=150)

# Decadal shift
df["Decade"] = (df["Year_of_Release"] // 10 * 10).astype("Int64")
ct = pd.crosstab(df["Decade"], df["Mutagen_Category"])
ct.plot(kind="bar", stacked=True, figsize=(11, 5))
plt.xticks(rotation=45, ha="right"); plt.tight_layout()
plt.savefig("mvd_mutagen_decade.png", dpi=150)

# Crop x Mutagen heatmap
top_crops = df["Crop"].value_counts().head(18).index
sub = df[df["Crop"].isin(top_crops)]
ct2 = pd.crosstab(sub["Crop"], sub["Mutagen_Category"])
sns.heatmap(ct2, annot=True, fmt="d", cmap="YlOrRd", figsize=(9, 10))
plt.tight_layout(); plt.savefig("mvd_crop_mutagen.png", dpi=150)

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")
# df = df[df["Crop"].str.contains("wheat", case=False, na=False)]

# Split multi-trait cells and count
all_traits = (df["Improved_Trait"].dropna()
              .str.split(r"[,;/&+]+", expand=True).stack()
              .str.strip().str.lower())
all_traits = all_traits[all_traits.str.len() > 2]
top20 = all_traits.value_counts().head(20)
print(top20)

# Categorise
def cat(t):
    t = str(t).lower()
    if any(k in t for k in ["yield","grain"]):               return "Yield"
    if any(k in t for k in ["disease","resist","blight"]):   return "Disease Resist."
    if any(k in t for k in ["drought","salinity","stress"]): return "Abiotic Stress"
    if any(k in t for k in ["matur","early"]):              return "Maturity"
    if any(k in t for k in ["quality","protein","oil"]):    return "Quality"
    if any(k in t for k in ["lodg","dwarf","height"]):     return "Plant Arch."
    return "Other"
all_traits.apply(cat).value_counts().plot(kind="pie", autopct="%1.1f%%",
    wedgeprops=dict(width=0.55), figsize=(7, 6))
plt.title("Trait Category Distribution")
plt.savefig("mvd_trait_cat.png", dpi=150); plt.show()

# Crop x Trait heatmap
df["Trait_Cat"] = df["Improved_Trait"].apply(cat)
top_c = df["Crop"].value_counts().head(15).index
ct = pd.crosstab(df[df["Crop"].isin(top_c)]["Crop"],
                 df[df["Crop"].isin(top_c)]["Trait_Cat"])
sns.heatmap(ct, annot=True, fmt="d", cmap="Blues", figsize=(12, 8))
plt.tight_layout(); plt.savefig("mvd_crop_trait.png", dpi=150)

TISSUE → OUTCOMECHI-SQUARE What it does: Cross-tabulates the treated explant (seed, callus, pollen, cutting, bulb…) against the resulting trait category. Tests whether the choice of starting tissue is statistically linked to the kind of improvement obtained.
  • Count heatmap: raw varieties per Explant × Trait Category combination
  • Row-normalised %: within each explant, what share of varieties target each trait — removes the dominance of common explants like seed
  • Chi-Square test: are explant and trait independent? Low p ⇒ tissue choice and breeding outcome are associated
  • Filters: narrow to a crop / species / region before testing

import pandas as pd
import seaborn as sns
from scipy.stats import chi2_contingency

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")

# Optional filter (crop / region) goes here
ct = pd.crosstab(df["Treated_Explant"], df["Improved_Trait"])

# Row-normalised percentages
ct_pct = ct.div(ct.sum(axis=1), axis=0) * 100
sns.heatmap(ct_pct, annot=True, fmt=".0f", cmap="viridis")

# Chi-Square test of independence
chi2, p, dof, expected = chi2_contingency(ct)
print(f"chi2={chi2:.2f}  p={p:.4f}  dof={dof}")

scipy.stats.chi2_contingency — χ², p-value, degrees of freedom, expected counts.
seaborn — annotated heatmap of the normalised table.
INFERENTIALNON-PARAMETRIC What it does: Formal hypothesis testing on MVD data — moves beyond counts to answerable statistical questions with p-values and effect sizes.
  • Chi-Square (χ²) Test: "Are two categorical variables statistically associated?" e.g. Is mutagen choice independent of crop group? Reports χ² statistic, df, p-value. Warning shown when expected cells <5 (merge rare categories)
  • Mann-Kendall (Detailed): filterable, year-bounded. Returns Kendall's τ, p-value, Sen's slope, and a dual-axis trend chart with slope line
  • Descriptive Stats (shown first): a plain-language summary and histogram for Year of Release, or for Mutagen Dose recovered from text (≈half the records, mostly Gy) — the single most useful enriched field for planning a treatment
🔢 Descriptive Statistics — Numeric Columns
DOSE FROM TEXT The MVD export has no dedicated dose column. Where a dose appears in a variety's description (e.g. "gamma rays (200 Gy)"), the suite extracts it into Mutagen Dose — recovered for roughly half of all records, almost always in Gy. Treat it as an indicative distribution of reported doses, not a complete census. Year of Release is fully numeric.

⌨ Python equivalent — Chi-Square Test
▼ 
import pandas as pd
from scipy.stats import chi2_contingency

df = pd.read_csv("MVD_DB.csv", encoding="utf-8-sig")
v1, v2, top_n = "Mutagen_Category", "Crop_Group", 10

t1 = df[v1].value_counts().head(top_n).index
t2 = df[v2].value_counts().head(top_n).index
sub = df[df[v1].isin(t1) & df[v2].isin(t2)]
ct = pd.crosstab(sub[v1], sub[v2])

chi2, p, dof, expected = chi2_contingency(ct)
print(f"chi2 = {chi2:.4f}   df = {dof}   p = {p:.6f}")
print("SIGNIFICANT" if p < 0.05 else "NOT significant")
if expected.min() < 5:
    print("Warning: min expected cell < 5 — merge rare categories")
scipy.stats.chi2_contingency — Computes χ² statistic, p-value, degrees of freedom, and expected cell counts from a 2D contingency table
pandas.crosstab — Builds the input contingency table from two categorical columns
